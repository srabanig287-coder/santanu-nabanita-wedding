PUBLISH TO GITHUB PAGES
1. Download and extract this ZIP.
2. In the GitHub repository santanu-nabanita-wedding, upload the CONTENTS of this folder (index.html and the assets folder), not the outer folder itself.
3. Commit the files to the main branch.
4. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to publish the site.
